# 🎮 Programação de Jogos

Repositório com exemplos práticos, exercícios e projetos voltados ao ensino de **programação de jogos**, com foco em lógica de programação, desenvolvimento interativo e aprendizado incremental.

---

## 📚 Objetivo

Este projeto tem como objetivo apoiar o ensino de programação através da construção de jogos, permitindo que estudantes:

- Desenvolvam raciocínio lógico
- Aprendam conceitos fundamentais de programação
- Trabalhem com interação gráfica
- Entendam estruturas como loops, condicionais e funções
- Apliquem conceitos de forma prática e visual

---

## 🧠 Abordagem Didática

A proposta segue uma abordagem **mão na massa**, onde cada jogo ou exercício:

- Introduz um novo conceito
- Evolui gradualmente em complexidade
- Incentiva experimentação e modificação
- Pode ser utilizado em sala de aula ou estudo individual

---

## 🕹️ Conteúdos Abordados

- Estruturas de decisão (if/else)
- Estruturas de repetição (loops)
- Variáveis e tipos de dados
- Funções
- Manipulação de eventos
- Lógica de jogos (pontuação, colisão, movimento)
- Animações básicas
- Interação com teclado/mouse
